# Tyche

Pump.fun for sports moments. Fans launch coins on in-game moments and storylines, every coin carries chapters that explain why its price moved, and the coins that hold up graduate to a Hall of Fame.

This is a play-money web prototype. Every price, trade and live chapter is simulated in the browser.

- Latest version: the site root
- Earlier version: `/v5/`

## Files

| File | What it is |
| --- | --- |
| `index.html` | The whole site |
| `coins.json`, `trending.json` | Sports moments the site loads |
| `version.json` | Build number, so phones pick up new versions |
| `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png` | Add-to-home-screen app icon and name |
| `v5/` | The previous version, kept live |

## Publish with GitHub Pages

Settings → Pages → Source: Deploy from a branch → Branch: `main`, folder `/ (root)` → Save. The site goes live at `https://<username>.github.io/<repo-name>/` within a minute or two.
